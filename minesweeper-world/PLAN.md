# 월드 마인스위퍼 (가제) — 게임 기획안

> 실제 세계지도를 500m 격자로 나눈 지뢰밭을 탐험하는 로그라이트 지뢰찾기 웹게임
> PC(마우스) · 모바일(터치) 동시 지원

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 지뢰찾기 + 로그라이트 (뱀파이어 서바이버류 성장 구조) |
| 플랫폼 | 웹 브라우저 (PC / 모바일), PWA로 홈 화면 설치 가능 |
| 맵 | 실제 세계지도. 육지 = 지뢰밭, 바다 = 이동 불가 지역 |
| 1칸 크기 | 약 500m × 500m (1칸 = 0.25km²) |
| 한 판(런) 길이 | 15~30분 목표, 중간 저장 후 이어하기 가능 |
| 핵심 재미 | ① 지뢰찾기 추론 ② 레벨업마다 3지선다 스킬 빌드 ③ 골드로 영구 성장 ④ "우리 동네를 지도에서 직접 열어본다"는 탐험감 |

### 핵심 루프

```
[상점/본부] → 출발 지역 선택 → [런 시작]
   → 칸 열기 → 경험치(XP)·골드 획득 → 레벨업 → 스킬 3개 중 1개 선택 (이번 런 한정)
   → 위험도 상승 (지뢰 밀도·특수 지뢰 증가)
   → 귀환 성공 or HP 0 → [결과 정산] → 골드로 영구 업그레이드 → 다시 출발
```

## 2. 맵 & 지뢰 규칙

### 2-1. 세계지도 격자
- **실제 해안선 데이터**(Natural Earth / OpenStreetMap)를 500m 격자로 변환해 육지 칸만 플레이 영역으로 사용.
- 격자는 웹 메르카토르 기반 정사각 격자. **기준 위도 35°(한국 부근)에서 정확히 500m**가 되도록 정의.
  - 적도 쪽은 칸이 약간 크고(≈610m), 북유럽 쪽은 작아짐(≈330m). "대략 500m" 감각을 유지하면서 구현이 가장 단순한 방식.
- 육지 전체는 약 **6억~10억 칸** 규모(남극 제외) → 미리 만들지 않고 **화면에 보이는 청크만 그때그때 생성**.

### 2-2. 지뢰 규칙
- 기본 규칙은 고전 지뢰찾기와 동일: 숫자 = 주변 8칸의 지뢰 수, 0이면 주변 자동 연쇄 오픈.
- 바다 칸은 지뢰 없음 & 열 수 없음 (숫자 계산 시 0으로 취급). 해안선이 자연스러운 맵 경계가 됨.
- 지뢰 배치는 `(시드, x, y)` 해시로 결정 → 같은 시드면 전 세계 어디서나 같은 지뢰 배치 (일일 도전/랭킹에 활용).
- **첫 클릭 안전**: 출발 지점 주변 3×3(영구 업그레이드로 5×5까지)은 지뢰 없음 보장.
- 섬 이동: 바다를 건너려면 **항구·다리 랜드마크**를 열거나 스킬 "다리 건설"이 필요.

### 2-3. 지역 난이도
- 지역마다 기본 지뢰 밀도가 다름 (예: 해안 도시 12~14%, 사막 18%, 험준한 산악 20%).
- MVP는 노이즈 기반으로 난이도를 배정하고, 이후 실제 지형/토지피복 데이터로 교체.

### 2-4. 런 진행에 따른 위험도 상승
열린 칸 수에 따라 단계적으로 어려워져 런이 무한히 늘어지지 않게 함.

| 위험 단계 | 조건(개방 칸) | 변화 |
|---|---|---|
| 1 | 0~800 | 기본 밀도 |
| 2 | 800~2,000 | 밀도 +2%p |
| 3 | 2,000~3,500 | 밀도 +4%p, **대전차 지뢰**(밟으면 HP -2) 등장 |
| 4 | 3,500+ | 밀도 +6%p, **재머 지뢰**(주변 숫자를 `?`로 가림) 등장 |

### 2-5. 특수 칸
| 칸 | 효과 |
|---|---|
| 💰 보물 상자 | 열면 골드 대량 획득 |
| 🏛 랜드마크 | 실제 지명(예: 부산항, 광안대교). 첫 발견 시 골드·XP 보너스 |
| ✈️ 귀환 포인트 | 공항·항구 랜드마크. 여기서 **귀환**하면 런 종료 + 골드 100% 보존 |
| ❤️ 구급 상자 | HP 1 회복 (드물게 등장) |

## 3. 조작 (PC / 모바일)

| 동작 | PC | 모바일 |
|---|---|---|
| 칸 열기 | 좌클릭 | 탭 (열기 모드) |
| 깃발 | 우클릭 | 롱프레스(진동 피드백) 또는 하단 "깃발 모드" 토글 후 탭 |
| 주변 일괄 열기(코드) | 숫자 칸 좌클릭 / 휠 클릭 | 숫자 칸 더블탭 |
| 줌 인/아웃 | **마우스 휠** (커서 위치 기준) | 핀치 줌 |
| 지도 이동 | 드래그, WASD/방향키 | 한 손가락 드래그 |
| 액티브 스킬 | 1~4 / Space | 하단 스킬 버튼 |

### 줌 단계 (LOD)
| 단계 | 화면 범위 | 표시 |
|---|---|---|
| 1 세계 | 전 세계 | 대륙, 내 탐사 흔적(히트맵) |
| 2 국가 | ~2,000km | 국경, 출발 가능 지역 |
| 3 지역 | ~200km | 열린 영역이 색 덩어리로 표시 |
| 4 도시 | ~50km | 칸 경계 표시, 숫자 숨김 |
| 5~6 플레이 | ~10~30km | 숫자·깃발 표시, **이 단계에서만 칸 조작 가능** |

- 모바일은 오조작 방지를 위해 플레이 단계에서 칸이 최소 28px 이상일 때만 입력 허용.

## 4. 경험치 & 레벨업 (런 한정 성장)

### 4-1. 경험치 획득
| 행동 | XP |
|---|---|
| 직접 클릭으로 연 안전 칸 | 2 |
| 연쇄(0)로 자동으로 열린 칸 | 0.5 |
| 지뢰 위 깃발이 정답으로 확정됨 | 1 |
| 랜드마크 발견 | 20 |

- 필요 XP: `30 + 15 × (현재 레벨 − 1)` → Lv1→2: 30, Lv7→8: 120, Lv14→15: 225
- 대략 **안전지대 20~60칸마다 1레벨** 체감, 한 런에서 Lv 12~18 도달 목표.

### 4-2. 레벨업 화면
- 게임이 일시정지되고 **카드 3장 중 1장 선택**.
- 카드 등급: 일반(회색) / 레어(파랑) / 에픽(보라) / 전설(금색).
- **다시 뽑기**(기본 1회, 영구 업그레이드로 증가), **건너뛰기**(골드 소량 획득).
- 스킬은 최대 5레벨. 한 런에서 보유 가능한 스킬은 최대 6개.

### 4-3. 스킬 목록 (초안)
| 분류 | 스킬 | 효과 (Lv1 → Max) |
|---|---|---|
| 탐지 | 📡 음파 탐지 | 안전 칸 40칸 → 20칸 열 때마다 근처 지뢰 1개 자동 깃발 |
| 탐지 | 🔍 탐침 | 선택한 칸이 안전한지 확인 (사용 횟수 2 → 6, 레벨업 시 충전) |
| 탐지 | 🧲 금속 탐지기 | 커서 주변 3×3의 지뢰 수 표시 (액티브, 쿨다운) |
| 탐지 | 🛰 항공 사진 | 반경 10칸의 지뢰 밀도를 히트맵으로 표시 |
| 탐지 | 🚁 정찰 드론 | 100칸마다 미개방 지역의 안전 칸 1~3개 자동 오픈 |
| 생존 | 🛡️ 방탄 조끼 | 실드 +1 (지뢰 피해 1회 무효), 150칸마다 재충전 |
| 생존 | ❤️ 강철 체력 | 최대 HP +1, 즉시 1 회복 |
| 생존 | 🩹 응급 처치 | 레벨업 시 HP 회복 확률 20% → 60% |
| 생존 | 🧯 불발탄 | 지뢰를 밟아도 10% → 30% 확률로 불발 |
| 경제 | 💰 황금 손 | 골드 획득 +20% → +80% |
| 경제 | 🗝 보물 사냥꾼 | 화면 안 보물 상자 방향 표시, 상자 골드 +50% |
| 경제 | 🔧 지뢰 해체반 | 정답 깃발 1개당 골드 +1 → +3 |
| 성장 | 📘 빠른 학습 | XP +15% → +60% |
| 성장 | ⚡ 연쇄 반응 | 연쇄 오픈 칸 XP 0.5 → 1.5 |
| 성장 | 🍀 행운 | 레어 이상 카드 등장 확률 증가 |
| 이동 | 🌉 다리 건설 | 바다 1~3칸 너머의 육지로 진입 가능 |

**진화 (뱀서식 조합)** — 두 스킬을 모두 Max로 만들면 레벨업 카드에 진화형이 등장
- 음파 탐지 + 항공 사진 → **🌍 위성 스캔**: 300칸마다 화면 안 지뢰의 30%를 공개
- 방탄 조끼 + 불발탄 → **🦾 폭발물 처리 슈트**: 실드가 있는 동안 지뢰를 밟으면 해체 처리 + 골드 획득
- 황금 손 + 보물 사냥꾼 → **👑 미다스**: 숫자 0 칸에서 동전이 나옴

## 5. 골드 & 런 종료

### 5-1. 골드 획득처
| 출처 | 양 |
|---|---|
| 안전 칸 오픈 | 칸당 확률적으로 1~3G |
| 보물 상자 | 30~150G |
| 랜드마크 첫 발견 | 50G |
| 깃발 정확도 보너스 (런 종료 시) | 정확도 90% 이상이면 정답 깃발 수 × 0.5G |
| 새 국가 첫 진입 | 500G (계정당 1회) |
| 일일 도전 순위 보상 | 순위별 |

### 5-2. 런 종료 조건
| 종료 방식 | 조건 | 골드 보존율 |
|---|---|---|
| ✈️ **귀환** | 귀환 포인트(공항·항구)에서 귀환 선택 | **100%** |
| 💀 **사망** | HP 0 | 50% (영구 업그레이드 "보험"으로 최대 75%) |

→ "더 깊이 들어가서 더 벌 것인가, 지금 귀환할 것인가"의 리스크/리워드 판단이 생김.

### 5-3. HP
- 기본 HP 3. 지뢰를 밟으면 HP -1(대전차 지뢰는 -2), 실드가 있으면 실드가 먼저 소모.
- 밟은 지뢰는 공개되고 자동으로 깃발 처리되어 게임은 계속 진행.

## 6. 상점 (영구 업그레이드, 런 사이에만 이용)

### 6-1. 능력치
| 업그레이드 | 효과 / 레벨 | 최대 | 비용(예시) |
|---|---|---|---|
| ❤️ 강인한 체력 | 시작 HP +1 | 5 | 600 → 1,200 → 2,400 … |
| 🛡️ 시작 실드 | 런 시작 시 실드 +1 | 3 | 900 → |
| 💰 골드 감각 | 골드 획득 +10% | 10 | 250 → (×1.5씩 증가) |
| 📘 빠른 학습 | XP +8% | 10 | 300 → |
| 🎲 행운의 주사위 | 레벨업 리롤 +1 | 3 | 1,500 → |
| 🎯 안전한 첫 발 | 첫 클릭 안전 범위 3×3 → 5×5 | 2 | 800 → |
| 🔍 탐침 키트 | 시작 시 탐침 +1 | 4 | 1,100 → |
| 🧳 보험 가입 | 사망 시 골드 보존 +5%p | 5 | 2,000 → |

### 6-2. 해금
- **스킬 해금**: 새 스킬을 레벨업 카드 풀에 추가 (처음엔 기본 8개만 등장).
- **4지선다**: 레벨업 카드 3장 → 4장 (고가, 탐험가 랭크 조건).
- **출발 지역**: 부산(기본) → 도쿄 · 파리 · 카이로 · 뉴욕 … 지역마다 난이도·보상 배율·랜드마크가 다름.
- (선택) 꾸미기: 깃발 디자인, 칸 스킨, 폭발 이펙트.

### 6-3. 메타 진행
- **탐험가 랭크**: 누적 탐사 면적(km²)으로 상승, 상점 상위 항목 해금 조건.
- **세계 탐사 도감**: 방문한 국가/랜드마크 수집 (예: 국가 3 / 195).
- **일일 도전**: 전 세계 동일 시드·동일 지역에서 점수 경쟁.

## 8. 기술 설계 (요약)

| 영역 | 방식 |
|---|---|
| 클라이언트 | TypeScript + Vite, 렌더링은 **PixiJS(WebGL)** — 수천 칸을 60fps로 그리기 위함 |
| 입력 | Pointer Events로 마우스/터치 통합, 휠·핀치 줌은 커서/손가락 위치 기준 |
| 지도 데이터 | 해안선 데이터를 **사전 처리**해 256×256칸 단위 육지 마스크 타일(1bit)로 저장 → 정적 CDN에서 필요한 타일만 로드. 전부 바다/전부 육지인 타일은 파일 없이 플래그만 |
| 지뢰 생성 | 시드 해시 함수로 칸별 지뢰 여부를 즉석 계산 (저장 불필요) |
| 연쇄 오픈 | 너비 우선 탐색을 프레임당 최대 N칸씩 나눠 처리 → 큰 0 영역에서도 멈춤 없이 퍼지는 연출 |
| 상태 저장 | 열린 칸·깃발 = 청크(64×64)별 비트셋 → IndexedDB에 자동 저장 (런 이어하기). 골드·업그레이드 = 로컬 저장, 이후 계정 서버 동기화 |
| 서버(후순위) | 일일 도전 랭킹, 계정 동기화, 부정 방지(시드 + 클릭 로그 검증) |

## 9. 밸런스 & 리스크 메모
- **무한 맵의 '찍기' 문제**: 무작위 배치 특성상 추론만으로 풀 수 없는 상황이 생김 → HP·실드·탐침으로 완화하고, 추론 불가 상황 감지 시 무료 탐침 1회 지급 옵션 고려.
- **연쇄 오픈 폭주**: 넓은 0 영역이 한 번에 수천 칸 열리면 XP 과다 → 연쇄 칸 XP를 낮게(0.5) 책정.
- **해안선 해상도**: 1:10m 데이터는 500m 격자 대비 다소 거칠음 → 알파부터 OSM 해안선(고해상도)으로 교체 검토.
- **모바일 성능**: 화면 밖 청크는 언로드, 저배율에서는 칸 대신 텍스처 1장으로 그림.

|---|---|

| **베타** | 일일 도전·랭킹, 계정 동기화, 도감·업적, 사운드·이펙트 다듬기 |

## 11. 결정이 필요한 사항
1. 바다를 완전히 막을지, 스킬/항구로 건너갈 수 있게 할지 (현재안: 항구·다리·스킬로 제한적 이동)
2. 사망 시 골드 50% 보존이 적당한지 (더 하드코어하게 0%도 가능)
3. 서버 없이 완전 오프라인 게임으로 시작할지, 처음부터 랭킹을 넣을지
4. 출발 지역을 정해진 도시로 제한할지, 세계 어디서나 시작 가능하게 할지
