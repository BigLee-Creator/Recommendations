# 📒 업무기록 시트 — 설치·사용 가이드

고객사 > 사업 > 업무별로 하루하루 일정과 노트를 기록하는 구글 스프레드시트입니다.
구글 캘린더(업무 / 할 일 / 개인)와 구글 주소록에 **양방향**으로 연동됩니다.

---

## 1. 설치 (처음 한 번, 약 10분)

필요한 파일은 `dist/` 폴더의 세 개입니다.

| 파일 | 붙여넣을 곳 |
|---|---|
| `dist/Code.gs` | Apps Script의 `Code.gs` |
| `dist/Sidebar.html` | Apps Script에 새로 만드는 HTML 파일 `Sidebar` |
| `dist/appsscript.json` | Apps Script의 `appsscript.json` (매니페스트) |

### 1-1. 시트 만들기
1. [sheets.new](https://sheets.new)에서 새 스프레드시트를 만들고 이름을 `업무기록_2026`으로 바꿉니다.
2. 메뉴 **확장 프로그램 > Apps Script**를 엽니다.

### 1-2. 코드 붙여넣기
1. 왼쪽 ⚙️ **프로젝트 설정**에서 **"편집기에서 'appsscript.json' 매니페스트 파일 표시"**를 체크합니다.
2. **편집기**(`< >`)로 돌아와서:
   - `appsscript.json` 내용을 모두 지우고 `dist/appsscript.json` 내용을 붙여넣습니다.
   - `Code.gs` 내용을 모두 지우고 `dist/Code.gs` 내용을 붙여넣습니다.
   - 파일 옆 **＋ > HTML**을 눌러 이름을 `Sidebar`로 만들고(확장자 없이), `dist/Sidebar.html` 내용을 붙여넣습니다.
3. 💾 저장(Ctrl+S)합니다.

### 1-3. 초기 설정 실행
1. 스프레드시트 탭으로 돌아가 **새로고침**합니다. 상단에 **📒 업무기록** 메뉴가 생깁니다.
2. **📒 업무기록 > 초기 설정 (처음 한 번)**을 누릅니다.
3. 권한 승인 창이 뜨면 계정을 고르고, "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 > (안전하지 않음)으로 이동**을 눌러 허용합니다.
   본인이 만든 스크립트라 이 경고가 뜨는 것이며, 데이터는 본인 계정 밖으로 나가지 않습니다.
   - 요청하는 권한: 스프레드시트, 캘린더, 주소록, Gmail 읽기(고객사 메일 연락 집계용), 메일 보내기(브리핑), 드라이브(새 연도 파일 복사)
4. 설정이 끝나면 아래가 자동으로 만들어집니다.
   - 시트: 대시보드, 기록, 월간, 검색, 분석, 고객사정보, 마스터, 연락처, 설정, 로그
   - 구글 캘린더: **업무**, **할 일** (개인 일정은 기본 캘린더를 사용)
   - 자동 실행: 캘린더 동기화(10분마다), 주소록 동기화(1시간마다), 자정 이월, 아침 브리핑, 주간 리포트, 연락 공백 계산

### 1-4. 종일 일정 알림을 "당일 오전 8:30"으로 (구글 캘린더에서 직접)
구글 캘린더는 API로 종일 일정의 당일 아침 알림을 지정할 수 없어서, 캘린더 설정에서 한 번만 지정합니다.
1. [calendar.google.com](https://calendar.google.com) > 오른쪽 위 ⚙️ **설정**
2. 왼쪽 **내 캘린더의 설정 > 업무 > 종일 일정 알림**: 기존 알림을 지우고 **알림 추가 → 0일 전(당일) 오전 8:30**
3. **할 일** 캘린더도 똑같이 설정합니다.

시간이 있는 일정은 스크립트가 **시작 1시간 전** 알림을 자동으로 넣습니다. 개인 캘린더의 알림 설정은 건드리지 않습니다.

### 1-5. 메일의 [완료 처리] 버튼 켜기 (웹앱 배포)
1. Apps Script 화면 오른쪽 위 **배포 > 새 배포**를 누릅니다.
2. 유형 선택 ⚙️ > **웹 앱**을 고르고, **다음 사용자 인증 정보로 실행: 나**, **액세스 권한: 나만**으로 설정한 뒤 **배포**합니다.
3. 나온 **웹 앱 URL**(…/exec)을 복사해 스프레드시트 **설정** 시트의 `웹앱 URL` 값에 붙여넣습니다.

### 1-6. 내 데이터 입력
1. **마스터**: 한 줄에 업무 하나씩 `고객사 | 사업 | 업무`를 입력합니다. 예시 행은 지워도 됩니다.
   - [구분], [분류]처럼 내 열을 **어디에든** 추가해도 됩니다. 스크립트는 1행 제목(`고객사`, `사업`, `업무`, `비활성`, `비고`)으로 열을 찾기 때문에, 이 다섯 개의 **제목 이름만 바꾸지 마세요.**
   - 입력창에서 새 업무를 추가하면, 추가한 열(구분 등)의 값은 같은 고객사 행에서 물려받습니다.
2. **연락처**: 고객사 담당자를 입력합니다. 1시간 안에 구글 주소록에 `고객사` 라벨로 들어갑니다.
3. **고객사정보**: 계약 시작·종료일과 연락 공백 기준(일)을 입력합니다. 고객사 목록은 마스터에서 자동으로 채워집니다.
4. 첫 캘린더 동기화는 **📒 업무기록 > 지금 캘린더 동기화**로 바로 실행할 수 있습니다. 올해 1월 1일부터 4주 뒤까지의 일정을 가져옵니다.

## 2. 매일 쓰는 법

### 기록하기
- **입력창(추천)**: **📒 업무기록 > 입력창 열기**를 누르면 오른쪽에 입력창이 열립니다.
  - 고객사를 고르면 그 고객사의 사업과 업무, 담당자만 나옵니다.
  - 담당자는 여러 명을 체크할 수 있습니다.
  - **+ 새 사업 / + 새 업무**로 바로 추가할 수 있습니다(마스터에 저장).
  - 유형을 '미팅'으로 고르면 노트에 `참석자 / 논의 / 결정 / 할 일` 양식이 채워집니다.
  - 기록 시트에서 행을 선택하고 **선택한 행 불러오기**를 누르면 수정할 수 있습니다.
- **시트에 직접 입력**: 기록 시트에 바로 적어도 됩니다. 날짜를 넣는 순간 상태, 캘린더 연동 같은 기본값이 채워집니다.

### 기록 시트의 열
`날짜 | 시작 | 종료 | 고객사 | 사업 | 업무 | 유형 | 제목 | 내용·노트 | 담당자 | 상태 | 다음 액션 | 다음 액션 기한 | 첨부 링크 | 이월 횟수 | 캘린더 연동`

- 오른쪽에 숨겨진 열(ID, 이벤트ID 등)은 연동용이니 **건드리지 마세요**.
- 정렬할 때는 **전체 행을 함께** 정렬하세요. 숨김 열까지 같이 움직여야 연결이 유지됩니다.

### 캘린더 연동 규칙

| 시트 | 캘린더 |
|---|---|
| 일반 고객사 행 | **업무** 캘린더, 제목 `[고객사/사업] 제목` |
| '다음 액션' + 기한 → 자동 생성된 작업 행 | **할 일** 캘린더, 기한 날짜에 종일 일정 `☐ [고객사/사업] 할 일` (완료 시 `✅`) |
| 고객사 `[개인일정]` | **개인**(기본) 캘린더, 제목 그대로 |
| 시작 시간이 없는 행 | 종일 일정 |
| 유형 '메모' | 캘린더에 올리지 않음 |
| 상태 취소 / 이월됨 / 재일정 필요 | 캘린더에서 내림 |

- **캘린더 → 시트**: 폰이나 웹 캘린더에서 만들거나 고친 일정은 10분 안에 시트에 반영됩니다.
  - 업무 캘린더에서 제목을 `[A사/사업1] 주간회의`처럼 쓰면 고객사와 사업이 자동으로 분류됩니다. 형식이 맞지 않으면 **미분류**로 들어오니 나중에 시트에서 고르세요.
  - 할 일 캘린더에서 제목 앞에 `✅`를 붙이면 시트에서 '완료'가 됩니다.
  - 캘린더에서 지운 일정은 시트에서 지우지 않고 상태만 **취소**로 바꿉니다.
- **시트 → 캘린더**: 시트에서 행을 지우면 캘린더 일정도 지웁니다.
  - 실수로 한꺼번에 많이 지운 경우(기본 20건 초과)에는 삭제를 멈추고 로그에 남깁니다. 의도한 것이면 **📒 업무기록 > 대량 삭제 승인 후 동기화**를 누르세요.
- **양쪽을 다 고쳤으면** 나중에 고친 쪽이 이기고, 로그 시트에 기록이 남습니다.
- 반복 일정은 **구글 캘린더에서** 만드세요. 앞으로 4주치 회차만 시트에 행으로 들어옵니다(매일 밤 새 회차 추가).
- **개인 캘린더의 생일 등 빼기**: 설정 시트의 `제외 키워드`(기본값 `생일`)가 제목에 들어간 개인 캘린더 일정은 시트에 넣지 않습니다. 이미 들어와 있던 행은 다음 동기화 때 시트에서만 빠지고, 캘린더 일정은 그대로 둡니다. 여러 개는 쉼표로 구분하고(`생일, 기념일`), 비우면 아무것도 빼지 않습니다. 업무·할 일 캘린더에는 적용되지 않습니다.
  - 구글 주소록의 '생일' 항목에서 자동으로 생기는 생일 일정은 원래부터 가져오지 않습니다.
- 고객사 담당자는 일정 설명에 이름만 적습니다. **참석자로 넣지 않으므로 고객사에 초대 메일이 가지 않습니다.**

### 자정 이월 (매일 0시대)
- 지난 날짜에 **'예정'**으로 남은 행은 원래 행을 **'이월됨'**으로 바꾸고, 오늘 날짜로 새 행을 만듭니다.
  - 작업, 메모: 시간 그대로 이월
  - 미팅, 통화: 시간 없이 **'재일정 필요'**로 이월. 시간을 정하고 상태를 '예정'으로 바꾸면 캘린더에 올라갑니다.
- '재일정 필요' 행은 날짜만 오늘로 옮기고 이월 횟수를 올립니다.
- **[개인일정]**은 이월하지 않고, 지난 일정은 자동으로 '완료'가 됩니다.
- '보류'는 그대로 둡니다.
- 이월 횟수가 3번 이상이면 빨간색으로 표시됩니다.
- 기본 상태값: 새 행은 날짜가 지났으면 '완료', 아니면 '예정'입니다. 메모는 '완료'입니다.

### 자동으로 오는 메일
- **아침 브리핑** (평일 8시 전후): 오늘 일정(개인 포함), 어젯밤 이월된 항목과 [완료 처리] 버튼, 곧 마감되는 할 일, 다시 잡아야 하는 미팅, 3번 넘게 밀린 항목, 연락이 뜸한 고객사, 계약 만료 임박, 미분류 일정
- **주간 리포트** (금요일 17시 전후): 고객사별 이번 주 활동, 시간, 다음 주 예정
- Apps Script 자동 실행은 정확한 분 단위가 아니라 **지정 시각 ±15분** 사이에 실행됩니다.

### 다른 시트
- **대시보드**: 오늘과 이번 주 일정, 마감 임박, 재일정 필요, 밀린 항목, 연락 공백, 계약 만료, 미분류 (실시간 수식)
- **월간**: B1에 아무 날짜나 넣으면 그 달의 달력이 보입니다. 🏠는 개인 일정입니다.
- **검색**: 고객사만 고르면 그 고객사의 전체 히스토리가, 키워드를 넣으면 노트까지 검색한 결과가 나옵니다. 작년 파일도 함께 찾습니다.
- **분석**: 기간을 넣으면 고객사, 사업, 유형별 시간과 건수를 차트로 보여 줍니다. 시작·종료 시간이 모두 있는 기록만 시간에 들어가며, 개인 일정은 빠집니다.
- **고객사정보**: 마지막 미팅·통화, 마지막 메일(연락처 이메일로 Gmail 검색, POP3로 가져온 회사 메일 포함), 공백 일수가 매일 아침 계산됩니다.
- **로그**: 동기화, 충돌, 오류 내역입니다. 문제가 생기면 여기부터 보세요.

### 시트 순서 / 이름
- 시트(탭) **순서는 마음대로 바꿔도 됩니다.** 스크립트는 시트를 이름으로 찾습니다.
- 시트 **이름은 바꾸지 마세요** (기록, 마스터, 연락처 등). 숨겨진 `_목록`, `_연동`, `_상태` 시트도 지우거나 이름을 바꾸면 안 됩니다.
- 기록·연락처·고객사정보 시트는 열 위치로 읽으므로 **중간에 열을 끼워 넣지 마세요.** 필요하면 맨 오른쪽(숨김 열 뒤)에 추가하세요. 마스터 시트만 예외입니다.

### 이름 바꾸기 / 그만 쓰는 항목
- 고객사, 사업, 업무 이름은 **📒 업무기록 > 고객사·사업·업무 이름 바꾸기**로 바꾸세요. 기록, 고객사정보, 연락처, 캘린더 제목이 함께 바뀝니다.
- 쓰지 않는 항목은 지우지 말고 마스터의 **비활성**에 체크하세요. 드롭다운에서만 숨겨지고 과거 기록은 그대로 남습니다.
- 연락처도 **비활성**에 체크하면 주소록에서 지우지 않고 라벨만 `고객사-이전`으로 바뀝니다.

## 3. 새해가 되면 (연도별 파일)
1. **1월 1일 이후** **📒 업무기록 > 새 연도 파일 만들기**를 누릅니다.
   - 같은 폴더에 `업무기록_2027` 파일이 생깁니다. 마스터, 연락처, 고객사정보, 설정, 스크립트가 복사됩니다.
   - 2027년 날짜의 기록(이월된 항목, 미리 잡아 둔 일정)은 새 파일로 옮겨집니다.
2. 새 파일을 열고 **📒 업무기록 > 초기 설정**을 한 번 실행해 권한을 승인합니다. 자동 실행은 파일마다 따로 등록되기 때문입니다.
3. 메일 버튼을 쓰려면 새 파일에서 **웹앱을 다시 배포**하고 URL을 설정 시트에 넣습니다.
4. 이전 파일은 1월 말까지 지난해 일정 변경만 반영하다가 자동 실행이 스스로 꺼집니다.

## 4. 설정 시트에서 바꿀 수 있는 값
브리핑 시각, 주간 리포트 시각, 연락 공백 기본(일), 마감 임박(일), 계약 만료 알림(일), 반복 일정 가져오기(일), 시간 일정 알림(분), 이월 경고 횟수, 대량 삭제 기준, 제외 키워드

- 색 기준값을 바꾼 뒤에는 **📒 업무기록 > 서식·대시보드 다시 적용**을 누르세요.
- 브리핑이나 리포트 시각을 바꾼 뒤에는 **초기 설정**을 다시 실행하세요. 데이터는 지워지지 않고 자동 실행만 새로 등록됩니다.

## 5. 알아 두면 좋은 점
- 개인 Gmail 계정의 자동 실행 한도(하루 90분) 안에서 동작하도록 만들었습니다. 10분 주기 동기화는 보통 한 번에 몇 초 걸립니다.
- 남이 보낸 초대 일정처럼 내가 고칠 권한이 없는 일정은, 시트에서 고쳐도 캘린더에는 반영되지 않습니다(로그에 남음).
- 파일을 다른 사람과 공유하면 개인 일정도 함께 보이니 주의하세요.
